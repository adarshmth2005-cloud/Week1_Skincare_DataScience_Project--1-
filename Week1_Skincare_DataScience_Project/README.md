
# Skincare Customer Preference & Product Review Analysis

## Project Overview
This project analyzes skincare customer preferences,
product ratings, skin types and skin concerns using Python.

## Objectives
- Analyze customer skin type preferences.
- Calculate average product ratings.
- Identify top-rated skincare products.
- Analyze product recommendation rates.
- Visualize product price distribution.

## Technologies Used
- Python
- Pandas
- Matplotlib

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the project:

python analysis.py

## Outputs
- Cleaned dataset
- Average rating chart
- Skin concern chart
- Product price distribution chart

## Conclusion
This project demonstrates data cleaning,
exploratory data analysis and data visualization
using Python.

Note: Dataset contains synthetic/demo records.
